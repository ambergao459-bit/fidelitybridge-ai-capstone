# FidelityBridge AI

Interactive six-stage workflow for capstone live demonstration.

Stages:
1. Intake
2. Extract
3. Classify
4. Generate
5. Score D1-D7
6. Review / QA Fix

Run locally:

```bash
pip install -r requirements.txt
python app.py
```

Deploy on Render:

- Build Command: `pip install -r requirements.txt`
- Start Command: `python app.py`
